# Service Desk

Sistema de **Service Desk** desenvolvido com **Vite**, criado para centralizar, organizar e acompanhar solicitações de suporte em um único ambiente.

## 📌 Sobre o projeto

O projeto tem como objetivo oferecer uma solução simples e eficiente para o gerenciamento de chamados de suporte, permitindo registrar solicitações, acompanhar seus status e facilitar a comunicação entre usuários e equipe de atendimento.

A aplicação está sendo desenvolvida utilizando **Vite**, proporcionando um ambiente moderno e rápido para desenvolvimento e execução do frontend.

## 🚀 Tecnologias

* [Vite](https://vitejs.dev/)
* JavaScript / TypeScript
* HTML5
* CSS
* Framework frontend utilizado no projeto

> As tecnologias e dependências podem ser atualizadas conforme a evolução do projeto.

## 🎯 Objetivos

* Centralizar solicitações de suporte;
* Facilitar o acompanhamento de chamados;
* Organizar o fluxo de atendimento;
* Melhorar a visibilidade das solicitações;
* Tornar o processo de suporte mais simples e eficiente.

## ⚙️ Instalação

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre no diretório do projeto:

```bash
cd service-desk
```

Instale as dependências:

```bash
npm install
```

## ▶️ Executando o projeto

Para iniciar o ambiente de desenvolvimento:

```bash
npm run dev
```

Após iniciar, o Vite disponibilizará a aplicação em um endereço local, normalmente:

```text
http://localhost:5173
```

## 🏗️ Build

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar localmente a versão de produção:

```bash
npm run preview
```
